# Identity Property
The identity property refers to the property of certain numbers (called identity elements) that
do not change the value of other numbers when used in a specific operation.

## Two Main Types of Identity Properties

### Identity Property of Addition
- The additive identity is 0
- Adding 0 to any number does not change it's value. (a + 0 = a and 0 + a = a)

Examples:
    7 + 0 = 7
    0 + (-3) = -3

### Identity Property of Multiplication
- The additive identity is 1
- Multiplying 1 to any number does not change it's value. (a * 1 = a and 1 * a = a)

Examples:
    9 * 1 = 9
    -5 * 1 = -5

## Key Points
- Every number has one additive identity (0) and one multiplicative identity (1).
- Identity elements are fundemental in algebra because they allow us to simplify expressions
  and solve equations.
- Inverse elements are related:
    Additive inverse: a + (-a) = 0
    Multiplicative inverse: a * (1/a) = 1 (for a != 0)
